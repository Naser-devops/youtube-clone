# 🎬 YouTube Clone

A YouTube-inspired frontend project built for practicing and improving **HTML & CSS** skills.

This project recreates the main visual structure of YouTube, including the header, search bar, sidebar navigation, and video cards.

---

## 📸 Project Overview

The project contains a YouTube-style interface with:

* 🎯 Header navigation
* 🔍 Search bar
* 🎤 Microphone button
* 📺 YouTube-style navigation icons
* 📂 Sidebar navigation
* 🎞️ Video cards
* 👤 Channel information
* 📊 Video views and upload time
* 📱 Responsive video layout using CSS Flexbox

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **CSS Flexbox**
* **Google Material Icons**
* **Google Fonts**
* **Lorem Picsum** for placeholder images

The project uses a separate CSS file connected to the HTML document.

## ✨ Features

### Header

The header contains:

* Menu button
* YouTube logo
* Search input
* Search button
* Microphone icon
* Video creation icon
* Apps icon
* Notifications icon
* Account icon

The header layout is built using CSS Flexbox.

### Sidebar

The sidebar contains navigation items such as:

* Home
* Explore
* Subscriptions
* Originals
* YouTube Music
* Library
* History
* Your Videos
* Watch Later
* Downloads
* Liked Videos

The navigation is structured using HTML links and Material Icons.

### Video Section

The main section contains multiple video cards.

Each video card includes:

* Video thumbnail
* Channel image
* Video title
* Channel name
* Views
* Upload time

The video layout uses Flexbox with wrapping so the cards can move to a new row when there isn't enough space.
